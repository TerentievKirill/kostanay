# Балапан — демонстрационный сайт детского сада

Рабочий статический прототип для частного детского сада в Костанае. Ориентир по разделам — tumar-kids.edu.kz. Вёрстка, тексты и иллюстрации самостоятельные.

## Запуск

Откройте index.html в браузере. Никакой сборки и зависимостей нет. При желании используйте python -m http.server 8080.

Включено:
- Русская и казахская версии с переключением.
- Адаптивные сетки, мобильное меню и три режима отображения.
- Разделы: главная, о саде, образовательная программа и группы, педагоги, документы/аттестация, родители и распорядок, контакты.
- Демонстрационные педагоги Тестер Анастасия, Тестер Ольга и Тестер Жанара.
- Встроенные SVG-иллюстрации вместо чужих фотографий.
- Служебная маркировка DEMO и запрет индексации.

## Что заменить до официального запуска

1. Полное юридическое имя, БИН, телефон, email, адрес, рабочий график.
2. Подтверждённые возрастные группы, программу, режим дня и питание.
3. Реальные данные педагогов и их квалификацию.
4. Загруженные PDF: устав, разрешительные документы, программа, материалы самооценки, приказы/протоколы, штатное расписание и тарификация в подлежащем публикации объёме. В index.html пока честные карточки со статусом «Ожидается», фальшивых документов нет.
5. Фотографии детсада (с правами на публикацию) и подтверждённую карту.
6. Проверенную казахскую версию официальных формулировок.
7. После согласования убрать демобаннер, robots.txt и метатег noindex.
8. Перенести на казахстанский хостинг, включить HTTPS и привязать официальный .edu.kz.
